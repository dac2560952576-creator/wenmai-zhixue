# 龙泉青瓷

## 基础介绍

龙泉青瓷是中国陶瓷史上烧制年代最长、窑址分布最广、生产规模和外销范围最大的青瓷历史名窑之一，始于三国两晋时期，距今已有1700余年历史。北宋中期初具规模，南宋中晚期进入鼎盛时期，至明代中叶渐趋衰落，2009年被联合国教科文组织列入人类非物质文化遗产代表作名录，填补"人类非遗"中陶瓷类的空白。

龙泉青瓷以"青如玉、明如镜、声如磬"著称，釉色涵盖粉青、梅子青、豆青等多种层次，其中粉青与梅子青被誉为青瓷釉色与质地之美的巅峰，可与翡翠媲美。龙泉窑产品曾大量外销至日本、韩国、东南亚、西亚、东非及欧洲各地，是宋元时期中国对外贸易的重要商品之一，也是海上丝绸之路的主要外销瓷器品种。

### 历史沿革

**三国两晋（起源期）**：龙泉地区开始烧制原始青瓷，胎质较粗，釉色青黄不均，器型简单，多为日用器皿。此时的龙泉窑尚处于萌芽阶段，技术主要受越窑影响。

**唐五代（发展期）**：烧制技术逐渐成熟，窑场数量增多。产品以碗、盘、壶等日用器为主，釉色由青黄转向青绿，装饰手法以刻划花为主，花纹简洁流畅。此时的龙泉窑已有一定规模，但尚未形成独特风格。

**北宋（成熟期）**：窑业初具规模，产品种类丰富，装饰技法以刻划花为主，印花也开始出现。釉色趋于稳定，青釉为多，胎质细密。北宋晚期，龙泉窑已开始向宫廷进贡瓷器，地位逐步提升。

**南宋（鼎盛期）**：政治中心南移至杭州，龙泉窑进入空前繁荣。南宋中晚期，章生一、章生二兄弟分别创立哥窑和弟窑两大流派。哥窑以开片纹为特色，紫口铁足，位列宋代五大名窑；弟窑以粉青、梅子青釉色著称，胎白釉青，无纹片。此时的龙泉青瓷工艺已达巅峰，产品远销海外，享有极高声誉。

**元代（持续繁荣）**：龙泉窑继续大规模生产，产量空前。元代龙泉青瓷胎体趋于厚重，器型变大，装饰手法以刻划、印花、贴花等多种技法并用，纹饰繁复华丽。产品大量出口，日本、东南亚等地均有大量元代龙泉青瓷出土。

**明代（渐趋衰落）**：明初洪武、永乐年间龙泉窑仍在生产，但景德镇窑的崛起和青花瓷的流行使龙泉青瓷逐渐失去市场。明代中后期，龙泉窑逐步衰落，但大窑一带仍有部分窑场维持生产。

**清代至今（复兴）**：清初龙泉窑基本停产。1957年，在周恩来总理"恢复青瓷生产"的指示下，龙泉青瓷进入了复兴阶段。1959年成立龙泉瓷厂，2009年入选人类非遗，现代龙泉青瓷在传承古法的基础上不断创新，焕发新的生命力。

| **梅子青** | 龙泉弟窑最上乘釉色，釉色葱翠深沉，釉层略带透明，光泽照人，如初生梅子般青翠欲滴 |
| **哥窑** | 龙泉青瓷两大流派之一，南宋中晚期章生一创立，以冰裂纹、蟹爪纹、牛毛纹等开片为装饰特色，紫口铁足，位列宋代五大名窑 |
| **弟窑** | 龙泉青瓷两大流派之一，章生二创立，胎白釉青，无釉裂，以粉青、梅子青为最，被誉为"民窑之巨擘" |
| **紫口铁足** | 哥窑典型特征，器口因釉薄而呈紫色（紫口），圈足底无釉处呈铁黑色（铁足） |
| **金丝铁线** | 哥窑开片纹路的雅称，粗纹呈深褐色如铁线，细纹呈黄褐色如金丝，交织成古朴典雅的装饰效果 |
| **冰裂纹** | 哥窑最典型的开片纹，裂纹层叠如冰块碎裂，线条流畅自然，有"裂而不破"之美 |
| **蟹爪纹** | 哥窑开片纹的一种，纹路细碎如蟹爪爬过的痕迹，多见于釉层较薄的部位 |
| **牛毛纹** | 哥窑开片纹的一种，纹路细密如牛毛，呈不规则的网状分布，较冰裂纹更加纤细 |
| **鱼子纹** | 哥窑开片纹的一种，裂纹细小圆润如鱼子，密集分布，多见于釉层较厚的部位 |
| **素烧** | 施釉前在750-820℃条件下对坯体进行的预烧处理，增强坯体强度，便于后续施釉 |

| **还原焰** | 烧成阶段控制窑内缺氧状态，使铁氧化物由Fe₂O₃转化为FeO，产生青绿色釉 |
| **氧化焰** | 烧成阶段窑内氧气充足，燃料充分燃烧，用于烧成的前期阶段（干燥、氧化阶段） |
| **出筋** | 弟窑青瓷有棱线处釉层较薄，微露白痕，与青釉形成对比的装饰效果 |
| **朱砂底** | 弟窑圈足底露胎处因紫金土含铁量高而呈橙红色 |
| **紫金土** | 龙泉当地特产的一种含铁量高的黏土（含铁量≥4%），用于配制青釉和制作哥窑胎体，是青瓷呈色的关键原料 |
| **石灰碱釉** | 龙泉青瓷使用的釉料类型，以石灰石和草木灰为助熔剂，高温下黏度大、不易流釉，可施厚釉，产生玉质感 |
| **匣钵** | 装烧时用于盛放瓷坯的耐火容器，保护器物不受烟尘和火焰直接侵袭，保证釉面光洁 |
| **垫饼** | 装窑时垫在器物圈足下的耐火泥饼，防止器物与匣钵粘连，烧成后敲掉 |
| **支钉** | 装烧时用于支撑器物的耐火小钉，多见于精细器物，烧成后在器物底部留下支钉痕 |

## 工艺流程

### 1. 原料制备

取龙泉当地瓷土、紫金土（含铁量≥4%）、石灰石等原料，经粉碎、淘洗、陈腐、练泥等多道工序，制备胎料与釉料。

**瓷土开采**：龙泉地区瓷土资源丰富，主要开采紫金土、高际砂、瓷石等。紫金土含铁量高达4%-8%，是龙泉青瓷呈色的关键。矿土采出后需在露天堆放数月，经风吹日晒雨淋使之自然风化，分解矿石结构，提高可塑性。

**粉碎与淘洗**：风化后的原料用石臼或水碓粉碎成细粉，过筛后加水搅拌成泥浆。泥浆经多次淘洗沉淀，去除粗颗粒和杂质，取上层细泥浆。这一工序决定了胎质的细腻程度，直接影响成品品质。

**陈腐与练泥**：细泥浆脱水后形成泥饼，放入地窖中陈腐数月甚至数年。陈腐过程使泥料中的有机物腐烂分解，水分均匀渗透，提高泥料的可塑性和稳定性。陈腐后的泥料经反复揉练、摔打（练泥），排出气泡，使泥质均匀致密。

**釉料配制**：釉料以石灰碱釉为基础，加入紫金土、石灰石、草木灰等，按家传秘方调配。釉料需在球磨罐中研磨数十小时，使颗粒细度达到要求。不同釉色配方不同——粉青釉含铁量约1%-2%，梅子青釉含铁量约2%-3%，还原烧成后呈现不同的青绿色调。

### 2. 拉坯成型

采用传统手工拉坯成型法或模具成型法，制作瓶、炉、罐、文房等器形。大件器物常分段拉制后拼接，需纯熟高超的手工技巧，胎薄釉厚的官窑作品成功率仅约1%。

**揉泥**：将练好的泥料在辘轳车上反复揉压，排出残余气泡，使泥质更加均匀。揉泥是拉坯前的基础工序，直接影响成型质量。

**拉坯**：将泥团置于陶轮中央，利用陶轮旋转的离心力，以双手控制泥团向上提拉、向外扩展，塑造成所需的器形。龙泉青瓷的经典器形有梅瓶、玉壶春瓶、凤耳瓶、贯耳瓶、弦纹瓶、鬲式炉、鼎式炉、笔洗、笔筒等。拉坯讲究手、眼、心的协调统一，要求匠人技艺娴熟、心手合一。

**修坯（利坯）**：坯体半干时，用修坯刀对坯体进行精细修整，削去多余的泥料，调整器壁厚薄和器形轮廓。修坯决定了器物的最终造型，要求刀法精准、线条流畅。

**接坯**：对于大件器物或复杂器形，需分段拉制各部件（如器身、器颈、器足、器耳等），再以泥浆黏接。接坯处需精心修整，使之浑然一体，不留痕迹。

**干燥**：成型后的坯体在阴凉通风处自然干燥，避免阳光直射和强风，防止坯体开裂。干燥时间根据器物大小和季节不同，从数天到数周不等。干燥后坯体含水率应低于3%。

### 3. 素烧处理

坯体晾干后，在750-820℃条件下进行素烧（预烧），历时5-8小时，增强坯体强度。素烧完成后自然冷却至室温，为施釉做准备。

**装窑**：素烧坯体按大小、形状分类装窑，窑内温度分布不均，需根据不同位置放置不同器物。中心高温区放大件，边角低温区放小件。

**素烧升温**：从常温缓慢升温至750-820℃，升温速度约100-150℃/小时。升温过快会导致坯体炸裂，过慢则浪费燃料。

**保温与冷却**：达到素烧温度后保温1-2小时，使坯体中的结晶水充分排出、有机物完全氧化分解。然后停火自然冷却至室温（约需12-24小时），方可开窑取坯。

### 4. 施釉装窑

龙泉青瓷采用独特的蘸釉法，施釉次数达4-5次，釉层厚度0.5-1.5毫米。釉层越厚，釉色越深，玉质感越强。

**施釉技法**：主要采用蘸釉法（浸釉法），即将素烧坯体浸入釉浆中，利用坯体的吸水性使釉浆均匀附着。每次浸釉后晾干再进行下一次浸釉，重复4-5次。也有使用浇釉法（淋釉法）和吹釉法的。器内壁通常用荡釉法——将釉浆倒入器内晃动后倒出。

**釉层厚度控制**：釉层总厚度需控制在0.5-1.5毫米。粉青釉偏厚（约1.0-1.5毫米），梅子青釉适中（约0.8-1.2毫米）。釉层过厚容易流釉（产生泪痕），过薄则釉色浅淡无玉质感。

**装窑技巧**：装窑时用匣钵盛装，以垫饼或垫圈垫烧。器物之间需保持适当间距，避免高温下釉料熔融流动黏连。哥窑和弟窑通常分窑烧制，因哥窑胎体含铁量高，烧成气氛要求不同。

### 5. 高温烧成

在龙窑中以木柴为燃料，经14小时左右高温烧制，烧成温度约1280-1300℃。烧成分为干燥、氧化、还原、成瓷、保温五个阶段，其中梅子青需在强还原条件下烧成，对窑温和气氛的控制要求极高，成品率仅约30%。

**干燥阶段（室温→300℃）**：缓慢升温，排出坯体残余水分，升温过快会导致坯体爆裂。历时约2-3小时。

**氧化阶段（300℃→950℃）**：窑门打开，充分供氧，使坯体中的有机物完全燃烧、碳酸盐分解、铁元素氧化为Fe₂O₃。此时釉面呈土黄色或红褐色。历时约3-4小时。

**还原阶段（950℃→1280℃）**：此阶段为关键。关闭窑门，减少供氧，投入湿柴或控制烟道闸门，使窑内产生大量一氧化碳，形成缺氧的还原气氛。在还原条件下，Fe₂O₃被还原为FeO，釉色由黄转青。还原气氛的强弱和时间长短决定了最终的釉色——轻度还原得粉青，强度还原得梅子青。历时约4-5小时。

**成瓷阶段（1280-1300℃保温）**：达到最高烧成温度后保温1-2小时，使釉料充分熔融流动，胎体瓷化完成。此阶段需精确控制温度——温度过低则釉面未熟，温度过高则釉面过烧起泡变形。

**冷却阶段（自然降温）**：停火后窑炉自然冷却，约需2-3天降至常温方可开窑。冷却速度也会影响釉色，缓冷有利于釉面析晶，产生玉质感。

**出窑与拣选**：开窑后逐件检查，按品质分为若干等级。一等品釉色纯正、器形规整、无瑕疵；二等品釉色略有偏差或器形小瑕；次品则回窑重烧或作废处理。传统龙窑的产品合格率约30%-40%，精品率更低。

## 典型纹样描述

### 莲瓣纹
层层叠叠的仰莲或覆莲造型，莲瓣饱满圆润，线条流畅，常见于瓶、炉等器物的腹部或足部。莲瓣边缘可略呈波浪状，中心起筋，有浮雕般的立体感，寓意清净高洁。南宋龙泉窑的莲瓣纹最为精美，瓣尖微翘，层次分明，与青釉的温润质感完美融合。

### 弦纹
平行环绕器物的凸线或凹线，简洁大方，可单道或多道组合。弦纹与青釉的光润质感相得益彰，增强器物的节奏感和层次感，常见于瓶、罐等器物的颈部或腹部。弦纹的间距和粗细变化是鉴定年代的重要依据——北宋弦纹较疏朗，南宋弦纹较紧密。

### 贴花纹
先用模具压出花片（如牡丹、莲花、鱼纹等），再以泥浆粘贴于坯体，贴花部分通常不上釉，烧成后呈紫红色，与青釉形成鲜明对比，红花绿叶，极为鲜艳。元代贴花工艺达到顶峰，牡丹花纹最为常见，花瓣层叠、枝繁叶茂。

### 蕉叶纹
细长的叶片层层相叠，叶尖上翘，排列整齐，常见于器物的颈部或足部边缘。蕉叶纹修长挺拔，与器物的稳重感形成动静对比。南宋龙泉窑蕉叶纹线条流畅，叶脉清晰，元代则趋于简化。

### 双鱼纹
两条鱼首尾相逐或相对而游，鱼身饱满，鳞片清晰，寓意"年年有余"。双鱼纹可采用刻划或贴花工艺，常见于盘、洗等器物的内底。元代双鱼洗是龙泉窑的经典器形之一，鱼纹生动活泼，深受国内外市场欢迎。

### 龙纹/鱼化龙
龙身矫健，鳞爪飞扬，常与云纹、水波相配。龙泉青瓷的龙纹多为暗刻或浅浮雕，若隐若现于青釉之下，神秘而庄重。元代龙纹五爪、四爪兼有，姿态凶猛；明代龙纹趋于规范化，以五爪龙为多。

### 缠枝纹
以藤蔓、枝叶相互缠绕的连续图案，可配以花卉（缠枝牡丹、缠枝莲花）、果实（缠枝葡萄）等。缠枝纹寓意连绵不断、生生不息，常见于器物的腹部。元代缠枝纹最为流行，构图饱满，线条流畅。

### 回纹
以横竖短线折绕组成的几何纹样，形如"回"字，寓意"富贵不断头"。回纹常见于器物的口沿、颈部或足部作为边饰，也可成片装饰于器物腹部。回纹规整严谨，与青釉的柔和形成了刚柔并济的效果。

## 代表器形

**梅瓶**：小口、短颈、丰肩、瘦底，因口小只能插梅枝而得名。龙泉窑梅瓶造型优美，线条流畅，是青瓷中的经典器形。南宋梅瓶偏于修长秀丽，元代梅瓶趋于高大厚重。

**玉壶春瓶**：撇口、细颈、垂腹、圈足，造型如"玉壶先春"之意，优雅端庄。龙泉窑玉壶春瓶多用于陈设和插花，粉青釉玉壶春瓶尤为珍贵。

**凤耳瓶**：直口、长颈、圆腹，颈部两侧贴饰凤形耳。凤耳造型生动，展翅欲飞，寓意吉祥。南宋龙泉窑凤耳瓶器形修长，凤耳精致，是官窑风格的代表作品。

**贯耳瓶**：器形仿商周青铜投壶样式，直口、长颈、扁圆腹，颈部两侧各有一贯耳（筒形耳），用于穿绳提携。贯耳瓶古朴庄重，多见于哥窑产品，开片纹与仿古造型相得益彰。

**鬲式炉**：仿商周青铜鬲的造型，三足、宽沿、短颈、鼓腹。龙泉窑鬲式炉线条简洁，釉色温润，是文房清供的经典器形。南宋鬲式炉三足外撇，器形沉稳；元代炉足趋于直立，器身变高。

**笔洗**：文房用具，用于盛水洗笔。龙泉窑笔洗造型多样，有圆洗、葵口洗、蔗段洗、双鱼洗等。笔洗器形小巧精致，釉色纯净，是文人的心爱之物。

**琮式瓶**：仿良渚文化玉琮造型，方柱形，外壁四面各以横线分隔，器形古朴神秘。南宋官窑和龙泉窑均有烧制，寓意"天圆地方"，用于陈设祭祀。

## 哥窑与弟窑的鉴别

| 特征 | 哥窑 | 弟窑 |
|------|------|------|
| 胎色 | 深灰、黑灰（含铁量高） | 白色、灰白色 |
| 釉色 | 青灰、青黄、炒米黄 | 粉青、梅子青、豆青 |
| 开片 | 有（冰裂、蟹爪、牛毛等） | 无开片 |
| 紫口铁足 | 典型特征 | 无（偶有朱砂底） |
| 釉面质感 | 半失透状，光泽柔和 | 失透状或半透明，光泽滋润 |
| 官窑地位 | 列为宋代五大名窑 | 民窑（品质不输官窑） |
| 铁线颜色 | 深褐色至黑色 | 不适用 |

## 鉴赏与收藏

**釉色鉴赏**：上品龙泉青瓷釉色纯正，粉青如秋日晴空，梅子青如翡翠初熟，无杂色、无斑点。釉面光润，有玉质感。灯光下观察，釉层应均匀透亮，无气泡、无针孔。

**器形鉴赏**：经典器形要求比例协调、线条流畅。梅瓶看肩线与腹线的过渡，玉壶春瓶看颈腹比例，炉看三足外撇角度。仿古器形需符合古制，创新器形需自成一格。

**开片鉴赏**（哥窑）：开片应自然流畅，无刻意为之的痕迹。冰裂纹以层叠交错为佳，金丝铁线以粗细分明为佳。开片颜色以深褐（铁线）配黄褐（金丝）为上品，单一黑色次之。

**胎体鉴别**：哥窑胎体沉重，叩之声音暗哑（因胎体含铁量高、瓷化程度较低）；弟窑胎体适中，叩之声音清脆（瓷化程度较高）。现代仿品胎体或过轻（瓷化过度）或过重（胎体未瓷化）。

**款识鉴别**：古代龙泉青瓷多为无款器，明清时期偶见"龙泉""大窑"等款。现代作品多有作者款识和年份款。需注意"加款"作伪——在老瓷上新刻款识以提高身价。

## 地域归属

**浙江省龙泉市及周边县市**

龙泉窑核心产区位于浙江省西南部丽水市下辖的龙泉市，以琉田（今龙泉市小梅镇大窑村）为中心，窑址分布于龙泉县及周边庆元、云和、丽水、遂昌、武义等县市，已发现古窑址达360多处。龙泉地处瓯江上游，拥有优质瓷土（紫金土、高际砂）和丰富的森林资源，为青瓷烧造提供了得天独厚的条件。

**各窑址群特点**：

**大窑窑址群**（小梅镇）：龙泉窑的核心产区，占地约6平方公里，已发现窑址60余处。南宋至元代为烧制御用和外贸精品的主要窑场，出土器物品质最高。大窑村至今保留着完整的古代龙窑遗迹。

**金村窑址群**（小梅镇）：位于大窑以南约3公里，以元代窑址为主，产品以日用瓷和外销瓷为主。金村窑产品胎体较厚，器形较大，装饰以刻划花和贴花为主。

**溪口窑址群**（查田镇）：以生产哥窑产品最为著名，南宋哥窑的核心产区。溪口窑出土的哥窑标本开片纹精美，紫口铁足特征典型，是研究哥窑的重要遗址。

**安福窑址群**（安仁镇）：以明代窑址为主，产品延续了龙泉青瓷的传统风格，但品质较南宋、元代有所下降。

**与其他名窑的区别**：

- **景德镇**：位于江西，以白瓷和青花瓷闻名，器型规整、胎质洁白，与龙泉青瓷的"青如玉"风格迥异。景德镇窑使用瓷石+高岭土的二元配方胎体，白度高于龙泉窑。
- **汝窑**：位于河南宝丰，同为宋代五大名窑之一，釉色天青、开片细密，但烧制时间短、产量稀少。汝窑釉层薄（约0.3-0.5毫米），龙泉窑釉层厚（0.5-1.5毫米），质感不同。
- **官窑**：南宋官窑位于杭州，产品专门供应宫廷，釉色粉青为主，开片规则细密。官窑胎体薄、釉层厚，与龙泉窑胎釉比例不同。

## 文化意义

龙泉青瓷不仅是中国陶瓷艺术的瑰宝，更是中华文明的重要载体。其温润如玉的釉质体现了儒家"君子比德于玉"的审美理想；其含蓄内敛的釉色反映了道家"大巧若拙"的哲学思想；其大量外销则见证了海上丝绸之路的文化交流。

龙泉青瓷对世界陶瓷史产生了深远影响。日本将龙泉青瓷称为"砧青瓷"，视为国宝级艺术品；法国的"雪拉同"（Celadon）一词即因龙泉青瓷而得名。现代，龙泉青瓷已成为中国文化的重要符号之一，2009年入选人类非遗标志着其全球文化价值的确认。

## 常见误解

### 误解1：青瓷就是青花瓷
**正解**：青瓷与青花瓷是完全不同的两类瓷器。青瓷是单色釉瓷，以铁为着色剂，釉色呈青绿色；青花瓷是釉下彩绘瓷，以钴料绘制图案后罩透明釉，烧成后呈蓝白相间的花色。

### 误解2：哥窑和弟窑是两个不同地方的窑口
**正解**：哥窑与弟窑均为龙泉青瓷的流派，相传为宋代章氏兄弟（章生一、章生二）在龙泉同地所创，并非两个独立窑口。哥窑以开片为特色，弟窑以无纹片的光洁青釉为特色。

### 误解3：所有龙泉青瓷都有开片
**正解**：只有哥窑系的龙泉青瓷有开片（冰裂纹等），弟窑系的龙泉青瓷釉层光洁无纹，以粉青、梅子青的纯净釉色取胜。

### 误解4：龙泉青瓷只有绿色
**正解**：龙泉青瓷虽以青色为主，但釉色变化丰富，包括粉青、梅子青、豆青、青灰、蟹壳青、炒米黄等，不同温度、气氛下可呈现多种色调。哥窑产品釉色范围更广，炒米黄、青灰色等均常见。

### 误解5：龙泉窑和南宋官窑是同一窑口
**正解**：南宋官窑（修内司官窑、郊坛下官窑）是专为宫廷烧造的官窑，位于杭州；龙泉窑是民窑，位于浙江龙泉，两者地理位置、产品用途、工艺细节均有区别。南宋晚期，龙泉窑曾承接部分宫廷用瓷的烧制任务，产品风格与官窑接近，但并非同一系统。

### 误解6：青瓷越绿越好
**正解**：龙泉青瓷的价值不以色深为贵，而以釉色的纯净度、玉质感和器形的典雅为评判标准。粉青釉色淡雅含蓄，梅子青釉色葱翠欲滴，各有千秋，不能简单以"绿不绿"论优劣。

### 误解7：现代龙泉青瓷不如古代
**正解**：现代龙泉青瓷在继承古法的基础上，借助现代科技手段在釉料配方、窑温控制、器形设计等方面均有长足进步。许多现代工艺大师的作品在釉色纯度和器形创新上已达到甚至超越古代水平。但在"古意"和历史价值上，古代青瓷有其不可替代的地位。
